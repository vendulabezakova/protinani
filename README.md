# Protínání

Vánoční rébus pro zeměměřiče. Statická stránka pro GitHub Pages, bez sestavování.

- `content.js` – všechny texty, kvíz a GA4 Measurement ID (tady se upravuje obsah)
- `app.js` – logika obrazovek
- `map.js` – mapa pro finále
- `styles.css` – vzhled

Užitečné odkazy:
- `?test=1` – testovací režim (nic se neměří, zapamatuje se v prohlížeči), `?test=0` ho vypne
- `?reset=1` – začít úplně od začátku
- `?debug=1` – měření s debug_mode (GA4 DebugView)
